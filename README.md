# 🚀 Meus Aprendizados em Linguagem C

Este repositório foi criado para registrar toda a minha evolução na linguagem C, desde os conceitos mais básicos até desafios avançados de lógica de programação.

---

### 🌟 Projeto Principal em Destaque

* **[O Confronto do Dragão](./11-Projects/)**: Um jogo de RPG em modo texto desenvolvido aplicando loops `while`, condicionais, geração de números aleatórios, tratamento de erros de digitação no buffer com `getchar()` e códigos ANSI para manipulação e atualização de tela estática no terminal. Abra a pasta para ver o código fonte!

---

### 📂 Estrutura de Exercícios de Fixação

Abaixo está a minha base de treinos diários, organizada de forma cronológica por assuntos:

* **[01. Variáveis e Entrada de Dados](./01_Variables_Data_input_output/)** — Primeiros passos com `printf`, `scanf` e tipos de dados.
* **[02. Estruturas Condicionais](./02_Conditional_Structures/)** — Tomadas de decisão com `if`, `else if` e `else`.
* **[03. Estruturas de Repetição](./03_Loops/)** — Controle de fluxo avançado com loops `while`, instruções `break` e `continue`.
